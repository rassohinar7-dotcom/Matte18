## Что нового

**Доставка иконок:** ожидание появления папки через AFC после ответа AirTraffic, до 30 секунд. Проверки типа и байтов сохранены.

**Чтение копии:** поддержка Manifest.plist в Snapshot при пустом корневом файле; XML с начальным пробелом. Вместо Invalid file показываются имя, размер и причина ошибки. Повреждённые файлы не принимаются за пустые настройки. При сбое чтения восстановление данного шага не запускается.

211 автоматических проверок прошли, включая отложенную видимость папок, вариант Snapshot и остановку до записи на повреждённой копии. Отчёт Windows 0.6.8 не содержит имени проблемного файла: исправленные сценарии воспроизведены, но точная причина на компьютере тестировщика и результат на физическом iPhone пока не подтверждены.

**Стекло:** эффект экспериментальных флагов не подтверждён. В отчёте с локально изменённой сборкой на iPad запрос принят, но блики остались. Поддержка iPad не добавлена. Исходные значения и отмена сохранены. Максимум размытия не реализован.

## Возможности

Две плитки открывают сгруппированные настройки. Всё выключено по умолчанию, применяются выбранные пункты. «Применённые настройки» читает известные переопределения из шести файлов и позволяет отменять выбранные значения. Источник записи и прежние значения чужих программ определить нельзя: отмена удаляет переопределение и возвращает выбор iOS.

Светлые иконки — дополнительные WebClip-ярлыки. Исходные системные иконки не заменяются. Сохранены исправления восстановления оборванной доставки и AirTraffic из предыдущих версий. Старые журналы нужны для отмены.

Закреплённый прогресс показывает завершённые этапы и проценты передачи iOS; 100% не означает подтверждение визуального эффекта.

## Проверки и совместимость

[Проверки Windows](https://github.com/rassohinar7-dotcom/Matte18/actions) проверяют опубликованный пакет, библиотеки, помощник AirTraffic и запуск окна без телефона. Это не проверка применения на реальном устройстве.

- macOS 14.4+, Intel runtime; на Apple Silicon нужна Rosetta.
- Windows 10 1809+ x64 и Windows 11 x64 с драйверами Apple.
- Управляемые настройки и просмотр: iPhone на 26.6.1 / 23G82. Визуальный результат для каждой модели не подтверждён.
- Подсказка блокировки: модели с жестовым управлением.

## Ограничения

Полный возврат iOS 18, старая анимация разблокировки и постоянно горящая полоска внутри приложений не реализованы. Полное исчезновение бликов не подтверждено. Сохранение прыгающей подсказки после перезагрузки подтверждал пользователь; это не подтверждает другие эффекты.

Перед изменениями нужна собственная резервная копия. Восстановление отдельных файлов может вызвать экран настройки iOS; сохранение пары Apple Watch не подтверждено. Приложение не отключает шифрование автоматически.

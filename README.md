Matte18 — приложение для выбора, применения и отмены известных настроек оформления iOS через USB. Проект находится в **бета-тестировании**. Полное удаление бликов и полный возврат интерфейса iOS 18 пока не подтверждены.

## Возможности

- **Две группы настроек:** для iOS 26.6.1 и общие изменения. Разделы открываются отдельными окнами с понятными подзаголовками.
- **Флаги бликов:** отдельные параметры Dock, папок, виджетов и системных отражений. В 0.6.6 добавлен экспериментальный путь через управляемые настройки Nugget.
- **Подсказка блокировки:** управляемый нулевой счётчик для подпрыгивающей полоски и надписи «Смахните вверх». Это отдельный механизм от полоски внутри приложений.
- **Штатные настройки доступности:** уменьшение движения, прозрачности и световых эффектов, каждая со своей галочкой.
- **Применённые настройки:** чтение известных параметров из шести файлов, в том числе значений, которые могли быть записаны GoldenNugget. Можно выбрать отдельные переопределения для удаления.
- **Дополнительные иконки:** импорт и подготовка наборов, экспериментальная USB-доставка WebClip. Это дополнительные ярлыки, а не замена системных приложений.
- **Статичные обои по версии iOS:** предпросмотр использует встроенные изображения; это не снимок экрана телефона.
- **Сохранение исходных значений, журналы, диагностика и отчёты.** Все новые изменения выключены при запуске.

## Как пользоваться

1. Распакуйте Mac-архив и откройте приложение либо запустите Windows EXE.
2. Подключите разблокированный iPhone по кабелю и подтвердите доверие компьютеру.
3. Выберите устройство и откройте нужную плитку настроек.
4. Отметьте только нужные пункты, нажмите **«Готово»**, затем **«Применить выбранное»**.
5. Для нового способа бликов дополнительно включите **«Флаги бликов: применить способом Nugget»**. Сам выбор способа без отмеченных флагов ничего не записывает.

Снятые ранее записанные пункты отменяются при общем применении. Если нужно сохранить уже включённую подсказку блокировки, оставьте её галочку включённой.

### Отменить настройку, установленную другим приложением

Откройте **«Применённые настройки» → «Прочитать настройки»**, отметьте нужные строки и выберите **«Отменить выбранные»**. Перед записью значения читаются повторно. Если выбранное значение изменилось, операция останавливается.

Список охватывает **известные параметры в шести фиксированных файлах**, а не любые изменения iOS. По значению нельзя достоверно определить программу, которая его записала. Для чужих изменений историческое значение неизвестно: отмена удаляет выбранное переопределение и возвращает выбор iOS.

## Статус беты и ограничения

- **Полное исчезновение бликов новым способом ещё не подтверждено на iPhone.** Предыдущие тесты записи в обычные пользовательские настройки не дали нужного эффекта.
- Для прыгающей подсказки получен положительный отзыв: она сохранялась после жёсткой перезагрузки и шести разблокировок. Неограниченное постоянство этим не доказано.
- Постоянная полоска внутри всех приложений и полный системный интерфейс iOS 18 **не реализованы**.
- Управляемые параметры и выборочная отмена используют восстановление выбранных файлов с последующим обычным перезапуском. Может появиться экран настройки iOS. **Сохранение пары Apple Watch этим способом не подтверждено.**
- Исходные копии сохраняются на компьютере. Шифрование резервных копий приложение автоматически не отключает. Перед экспериментами нужна собственная резервная копия.
- Чтение исходных настроек может занимать несколько минут. Принятие запроса iOS не считается подтверждением визуального результата.
- Для 0.6.6 прошли **179 автоматических проверок** и проверка запуска Mac после распаковки. **Нативный запуск Windows и новые эффекты на физическом iPhone не проверены.**

## Изменения 0.6.6

- Новый путь записи отмеченных флагов бликов в управляемый `.GlobalPreferences.plist`.
- Просмотр известных параметров из шести файлов и выборочная отмена переопределений.
- Обновление локальных журналов, чтобы последующая отмена Matte18 не возвращала явно удалённое значение.
- Две большие плитки вместо раскрывающихся секций, отдельные окна и тематические подзаголовки.
- Кнопка «Применённые настройки» над «О проекте»; удалён заголовок «Оформление».
- Сохранены синяя иконка, фон с сине-чёрным градиентом и доступность для всех моделей iPhone на 26.6.1/23G82.
- Из названия приложения и файлов убрана пометка `test1`; статус релиза — **Beta / Pre-release**.

## Что нового

- Отдельная галочка «Матовые кнопки блокировки — эксперимент»: выбранный флаг с сохранением исходного значения и отменой. Может затрагивать другие системные кнопки. Точная полупрозрачность как на iOS18 не подтверждена.
- Отдельные настройки часов и стеклянного преломления при разблокировке, в управляемом файле SpringBoard. Счётчик подсказки сохраняется.
- Новые пункты выключены по умолчанию. Раздел блокировки отделён в списке настроек.
- Сохранены исправления 0.6.10: ожидание папок иконок после AirTraffic, чтение Manifest.plist из Snapshot при пустом корневом файле, подробная диагностика и закрытие SQLite в Windows.

## Проверки

218 автоматических проверок прошли в упакованной Mac-сборке. [Windows-проверка](https://github.com/rassohinar7-dotcom/Matte18/actions) запускает полный набор в опубликованном пакете, проверяет зависимости, изолированный помощник AirTraffic и окно приложения. Проверяются выбор пунктов, применение/отмена на тестовых данных, сохранность посторонних значений, иконки, восстановление после сбоев и прогресс. Это не визуальная проверка iPhone и не гарантия эффекта каждого экспериментального флага.

## Возможности

Две плитки открывают сгруппированные настройки. Всё выключено по умолчанию. «Применённые настройки» читает известные переопределения из шести файлов и позволяет отменять выбранные значения. Прежние значения чужих программ определить нельзя: отмена удаляет переопределение и возвращает выбор iOS.

Светлые иконки создаются как дополнительные WebClip-ярлыки. Системные иконки не заменяются. Старые журналы нужны для отмены. Закреплённый прогресс показывает завершённые этапы и проценты передачи iOS.

## Совместимость и ограничения

- macOS 14.4+, Intel runtime; на Apple Silicon нужна Rosetta.
- Windows 10 1809+ x64 и Windows 11 x64 с драйверами Apple.
- Управляемые настройки и просмотр: iPhone на 26.6.1 / 23G82. Подсказка блокировки — модели с жестовым управлением.

Матовые кнопки используют SBDisallowGlassButtons=true в управляемых глобальных настройках. Реестр GoldenNugget описывает флаг для iOS27; на 26.6.1 он добавлен по запросу пользователя как эксперимент. Числовая прозрачность кнопок не регулируется.

Постоянная полоска внутри всех приложений, полный возврат iOS18 и старая анимация разблокировки не реализованы. Полное удаление бликов и системный максимум размытия не подтверждены. В отчёте с модифицированной сборкой на iPad блики остались; поддержка iPad не добавлена. Подсказка «Смахните вверх» управляется отдельно. Сбор и отправка ошибок отложены до 7.0.1, автоматической передачи данных нет.

Перед экспериментами нужна собственная резервная копия. Восстановление отдельных файлов может вызвать экран настройки iOS; сохранение пары Apple Watch не подтверждено. Приложение не отключает шифрование автоматически.

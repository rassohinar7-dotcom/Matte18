## Что нового

- Отдельная галочка «Матовые кнопки блокировки — эксперимент»: сохранение исходного значения и отмена. Может затрагивать другие системные кнопки. Точная полупрозрачность как на iOS18 не подтверждена.
- Отдельные настройки часов и стеклянного преломления при разблокировке в управляемом файле SpringBoard. Счётчик подсказки сохраняется. Новые пункты выключены по умолчанию.
- Сохранены исправления 0.6.10: ожидание папок иконок после AirTraffic, чтение Manifest.plist из Snapshot при пустом корневом файле, подробная диагностика и закрытие SQLite в Windows.
- Журналы с русским текстом читаются в UTF-8 независимо от языка Windows.

## Проверки

219 проверок прошли в пересобранном Mac-приложении. [Windows-проверка](https://github.com/rassohinar7-dotcom/Matte18/actions) проверяет опубликованный пакет: полный набор тестов, зависимости, помощник AirTraffic и запуск окна. Проверяются выбор пунктов, применение и отмена на тестовых данных, сохранность посторонних значений, иконки, обработка сбоев и прогресс. Это не визуальная проверка iPhone и не гарантия эффекта экспериментальных флагов.

## Возможности

Две плитки открывают сгруппированные настройки. Всё выключено по умолчанию. «Применённые настройки» читает известные переопределения из шести файлов и позволяет отменять выбранные значения. Прежние значения чужих программ определить нельзя: отмена удаляет переопределение и возвращает выбор iOS.

Светлые иконки — дополнительные WebClip-ярлыки. Системные иконки не заменяются. Старые журналы нужны для отмены. Прогресс показывает завершённые этапы и проценты передачи iOS.

## Совместимость и ограничения

- macOS 14.4+, Intel runtime; на Apple Silicon нужна Rosetta.
- Windows 10 1809+ x64 и Windows 11 x64 с драйверами Apple.
- Управляемые настройки и просмотр: iPhone на 26.6.1 / 23G82. Подсказка блокировки — модели с жестовым управлением.

Матовые кнопки используют SBDisallowGlassButtons=true в управляемых глобальных настройках. Реестр GoldenNugget описывает флаг для iOS27; на 26.6.1 он добавлен по запросу пользователя как эксперимент. Прозрачность численно не регулируется.

Постоянная полоска внутри всех приложений, полный возврат iOS18 и старая анимация разблокировки не реализованы. Полное удаление бликов и системный максимум размытия не подтверждены. Поддержка iPad не добавлена. Подсказка «Смахните вверх» управляется отдельно. Автоматической отправки данных нет.

Перед экспериментами нужна собственная резервная копия. Восстановление отдельных файлов может вызвать экран настройки iOS; сохранение пары Apple Watch не подтверждено. Приложение не отключает шифрование автоматически.

## Исправления в 0.6.7

- Исправлена ошибка Errno 2 при первом чтении применённых настроек: папка снимка создаётся до проверки диска. Ошибки просмотра больше не сопровождаются предупреждением о возможной записи.
- Исправлено продолжение оборванной доставки иконок и удаление незавершённого набора. Повторная установка использует те же идентификаторы, без дубликатов.
- Соединение AFC обновляется после каждого этапа AirTraffic, передача ограничена группами до восьми папок.
- Исходные файлы Books сохраняются и возвращаются. Живая база Books, WAL/SHM и чужие иконки не перезаписываются и не удаляются.
- Сохранено исправление win32security для Windows.

## Возможности

Две большие плитки открывают сгруппированные настройки: «Только для 26.6.1» и «Изменения для всех версий». Параметры выключены по умолчанию и применяются после выбора галочек.

«Применённые настройки» читает известные переопределения из шести файлов, в том числе оставленные GoldenNugget. Можно выбрать отдельные значения для отмены. Перед отменой выполняется повторное чтение; изменившееся значение блокирует запись. Для чужих изменений исторические значения неизвестны: отмена удаляет переопределение, возвращая выбор iOS. Источник записи определить нельзя.

Светлые иконки устанавливаются как дополнительные WebClip-ярлыки. Это не замена исходных системных иконок. Их появление и запуск после USB-доставки требуют проверки на устройстве. Старые журналы не удаляйте — они нужны для восстановления оборванной доставки.

Управляемые флаги бликов применяются экспериментальным способом Nugget. Полное отключение бликов, полный возврат iOS 18 и постоянная полоска внутри всех приложений не подтверждены или не реализованы. Для прыгающей подсказки блокировки получен положительный отзыв пользователя после нескольких разблокировок; это не подтверждает остальные эффекты.

## Совместимость

- macOS 14.4+. Комплект использует Intel runtime; на Apple Silicon нужна Rosetta.
- Windows 10 1809 (17763)+ x64 и Windows 11 x64.
- Управляемые флаги, подсказка и просмотр/отмена: iPhone на iOS 26.6.1 / 23G82. Подсказка полоски предназначена для моделей с жестовым управлением.
- Общие USB-параметры: профиль 26.6.1–27.0.1 с проверкой доступа перед записью. Разрешение модели не гарантирует одинаковый визуальный эффект.

## Проверка

190 автоматических проверок прошли. Ошибка первого чтения настроек воспроизведена до исправления; после исправления чтение проходит без записи и перезапуска. Проверены обрывы связи, повторная установка и сохранность чужих данных. Mac проверен запуском приложения. [Проверки Windows](https://github.com/rassohinar7-dotcom/Matte18/actions). При подготовке 0.6.7 iPhone не подключён: новые операции на физическом устройстве пока не подтверждены.

## Перед применением

Сделайте собственную резервную копию. Восстановление выбранных файлов может вызвать экран настройки iOS; **сохранение пары Apple Watch не подтверждено**. Приложение автоматически не отключает шифрование. Чтение резервной копии может занять несколько минут. Без выбранных параметров запись не выполняется.

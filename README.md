## Что нового

- Явное закрытие соединений SQLite с Manifest.db: файлы копии больше не удерживаются открытыми в Windows после чтения.
- Ожидание появления папки иконок через AFC после ответа AirTraffic, до 30 секунд. Проверки типа и байтов сохранены.
- Поддержка Manifest.plist в Snapshot при пустом корневом файле; XML с начальным пробелом. Вместо Invalid file — имя, размер и причина ошибки. Повреждённые файлы не считаются пустыми настройками. При сбое чтения восстановление данного шага не запускается.

211 автоматических проверок прошли. [Проверки Windows](https://github.com/rassohinar7-dotcom/Matte18/actions) дополнительно проверяют опубликованный пакет, зависимости, помощник AirTraffic, запуск окна и 36 сценариев чтения копии и доставки иконок без телефона.

Отчёт Windows 0.6.8 не содержит имени проблемного файла: исправлены воспроизведённые сценарии, но точная причина на компьютере тестировщика и результат на физическом iPhone пока не подтверждены.

## Возможности

Две плитки открывают сгруппированные настройки. Всё выключено по умолчанию, применяются выбранные пункты. «Применённые настройки» читает известные переопределения из шести файлов и позволяет отменять выбранные значения. Источник записи и прежние значения чужих программ определить нельзя: отмена удаляет переопределение и возвращает выбор iOS.

Светлые иконки — дополнительные WebClip-ярлыки. Исходные системные иконки не заменяются. Сохранены исправления восстановления оборванной доставки и AirTraffic. Старые журналы нужны для отмены.

Закреплённый прогресс показывает завершённые этапы и проценты передачи iOS; 100% не означает подтверждение визуального эффекта.

## Совместимость и ограничения

- macOS 14.4+, Intel runtime; на Apple Silicon нужна Rosetta.
- Windows 10 1809+ x64 и Windows 11 x64 с драйверами Apple.
- Управляемые настройки и просмотр: iPhone на 26.6.1 / 23G82. Подсказка блокировки — модели с жестовым управлением. Визуальный результат для каждой модели не подтверждён.

Полный возврат iOS 18, старая анимация разблокировки и постоянно горящая полоска внутри приложений не реализованы. Полное исчезновение бликов и максимум размытия не подтверждены. В отчёте с локально изменённой сборкой на iPad запрос принят, но блики остались; поддержка iPad не добавлена. Эксперимент стекла помечен как не подтверждённый, исходные значения и отмена сохранены. Сохранение прыгающей подсказки после перезагрузки подтверждал пользователь; это не подтверждает другие эффекты.

Перед изменениями нужна собственная резервная копия. Восстановление отдельных файлов может вызвать экран настройки iOS; сохранение пары Apple Watch не подтверждено. Приложение не отключает шифрование автоматически.
